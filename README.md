# Healthcare Data Analysis Project

## Project Overview
Analyzed 55K+ healthcare records using Python, Pandas, Seaborn, and Matplotlib to identify patient, billing, and hospital trends.

## Key Features
- Data Cleaning & Preprocessing
- Missing Value Handling
- Duplicate Record Removal
- Datetime Conversion
- Exploratory Data Analysis (EDA)
- Data Visualization

## Insights Generated
- Top recurring medical conditions
- Patient age-group distribution
- Hospital stay duration trends
- Insurance billing analysis
- Hospital-wise patient distribution

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS code

## Project Outcome
Generated healthcare insights to support patient management, hospital resource planning, and billing analysis.
